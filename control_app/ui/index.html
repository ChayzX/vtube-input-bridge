    PC link

    The encrypted connection that lets the Stream Deck reach apps on both PCs.

    This PC's local IPv4 address on your home network. The other PC connects to it.

    Pairing

    Not paired
    Export this PC's pairing file, copy it to the other PC and import it there. Then do the same the other way round, and delete the copies.
    Pairing files
    A pairing file holds a connection key. Move it with a USB stick or a private message, never a public link.

    Remote controls

    Remote controls
    Lets Stream Deck keys control apps on this PC, and shows reactives. Turning it off is the same as Pause remote controls in the tray.

    Apps on this PC

    Which apps on this PC the Stream Deck may control, and how to reach them.

    OBS Studio
    Switch scenes from the Stream Deck.
    Default ws://127.0.0.1:4455
    From OBS › Tools › WebSocket Server Settings. Stored encrypted.
    VTube Studio
    Trigger hotkeys and Item Scenes. VTube Studio asks once to allow VTube Control.
    Default ws://127.0.0.1:8001. Turn on Start API in VTube Studio's settings.
    Meld Studio
    Switch scenes in Meld Studio instead of OBS.
    Default ws://127.0.0.1:13376. In Meld, turn on Settings › Advanced › Allow remote connections.
    Spotify
    Play, pause, next and previous track. Spotify must be open on this PC.

    Reactives

    Discord reactive avatars from Fugi, shown on stream in VTube Studio.

    Render reactives on this PC
    Discord runs on this PC, so the Fugi overlay is drawn here and sent to the Streaming PC.
    In Fugi, copy the group (or individual) browser-source link.
    Fugi account
    Sign in once. The sign-in window is never sent to the Streaming PC.

    Renderer

    Stopped
    Starts by itself when the app starts and after you save, once the PCs are paired and a Fugi URL is saved.
    In VTube Studio, add a Web Item with this address and turn on transparency. Then save it in an Item Scene.
    Waiting for images
    Images come from the renderer on the Gaming PC. Show or hide them with a Stream Deck key.
